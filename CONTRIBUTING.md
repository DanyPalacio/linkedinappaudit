# Contributing to Personal Branding Audit AI

Thank you for your interest in contributing! 🎉

## How to Contribute

### **1. Report Bugs**
- Open a GitHub Issue
- Describe the bug clearly
- Include steps to reproduce
- Mention your environment (OS, browser, Node version)

### **2. Suggest Features**
- Open a GitHub Issue with label `enhancement`
- Explain the feature and its value
- Discuss before implementing

### **3. Submit Code**

**Steps:**
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test thoroughly
5. Commit: `git commit -m "Add: your feature description"`
6. Push: `git push origin feature/your-feature`
7. Open a Pull Request

**Commit message format:**
- `Add:` for new features
- `Fix:` for bug fixes
- `Update:` for improvements
- `Docs:` for documentation

### **4. Code Style**

- Use clear, descriptive variable names
- Comment complex logic
- Follow existing code patterns
- Keep functions small and focused

### **5. Testing**

Before submitting:
- ✅ Test locally
- ✅ Verify no console errors
- ✅ Check mobile responsiveness
- ✅ Test with real profile data

## Development Setup

```bash
git clone https://github.com/DanyPalacio/personalbranding-audit.git
cd personalbranding-audit
npm install
cp .env.example .env
# Add your API keys to .env
npm start
```
