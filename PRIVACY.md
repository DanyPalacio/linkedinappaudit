## 1. Overview

## 2. Information We Process

### **Profile Information (Not Stored)**

When you use the Software, you provide:
- Name, headline, about/summary text
- Work experience, skills
- Number of followers, Premium status, Verification status
- Screenshots of posts (images)

**IMPORTANT:** This information is:
- ✅ Processed in real-time
- ✅ Sent to Anthropic Claude API for analysis
- ❌ **NOT stored** on our servers
- ❌ **NOT saved** to any database

### **Analytics Data (Google Analytics)**

We collect anonymous usage data:
- Page views, session duration, browser type
- Geographic location (country/city level)
- Device type, referral source
